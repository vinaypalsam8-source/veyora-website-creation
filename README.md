## 🌟 Key Features

- **Modern Blue & White Aesthetics**: Clean ice-white and glowing sapphire aesthetic with frosted glassmorphism and dual light/dark mode.
- **5 Interactive Website Demos**:
  - 💳 **Lumina Pay** — Fintech & Web3 SaaS with live currency converter & payment simulator.
  - 🏥 **Aura Dental & Wellness** — Luxury medical & booking portal with interactive scheduler.
  - 🤖 **NovaForge AI** — Developer tool & AI platform with live terminal prompt playground.
  - 🌸 **Elysian Bloom** — Haute parfumerie e-commerce boutique with interactive scent swatches & cart.
  - 🏛️ **Horizon Living** — Prime architectural real estate with interactive mortgage & yield calculator.
- **Live Device Frame Sandbox**: Test all 5 websites in Desktop, Tablet, and Mobile simulated viewports.
- **Interactive Project Cost & Timeline Estimator**: Real-time project price calculation and scope builder.
- **Services & 4-Stage Creation Engine**: Detailed roadmap and service catalog.
- **Client Impact & Testimonials**: Verified case study metrics.
- **Consultation Scheduler**: Direct inquiry form with instant validation.

## 🚀 Live Demo & Deployment

### Quick Local Run
Simply open `index.html` in any web browser, or run:
```bash
# Using Node / npx
npx serve .

# Or using Python
python -m http.server 8080
```

### GitHub Pages Setup
To host this portfolio on **GitHub Pages** for free:
1. Push this repository to your GitHub account.
2. Go to **Settings** > **Pages**.
3. Under **Branch**, select `main` (or `master`) and `/ (root)`.
4. Click **Save**. Your site will be live at `https://<your-username>.github.io/<repo-name>/`!
